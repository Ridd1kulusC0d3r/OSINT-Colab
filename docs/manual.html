Como funciona

Modelos de IA leem textos e imagens de fontes abertas e devolvem decisões com probabilidade. O núcleo OSINTIA, em Python puro, mede se essa probabilidade merece confiança e manda para você tudo o que estiver em dúvida.

A ideia central: confiança calibrada não é verdade. É concordância com quem rotulou o gabarito. Por isso o OSINTIA audita o gabarito antes de você confiar no modelo.

Instalação passo a passo

Não precisa instalar nada. Funciona em qualquer sistema com um navegador e uma conta Google.

  1. No README do repositório, clique no botão Open in Colab do notebook desejado.
  2. Para os notebooks 01, 03, 05 e 06: menu Ambiente de execução → Alterar o tipo de ambiente de execução → T4 GPU → Salvar.
  3. Menu Ambiente de execução → Executar tudo.
  4. Se aparecer o aviso "Este notebook não foi criado pelo Google", clique em Executar mesmo assim.

  2. No GitHub, clique em Code → Download ZIP e descompacte.
  3. Dê dois cliques em rodar-no-windows.bat.
  4. Se o Windows SmartScreen avisar, clique em Mais informações → Executar assim mesmo.

Gerando relatórios

Todo notebook grava arquivos em /content/saidas/ e um manifesto.jsonl. Baixe a pasta pelo painel de arquivos do Colab (ícone de pasta, à esquerda).

Para conferir a integridade depois: python -m osintia verificar saidas/manifesto.jsonl. Para remover dados pessoais de um texto: python -m osintia mascarar "...".

No relatório, use o código do Almirantado (ex.: B2), cite a fonte original e registre o modelo, a versão e o limiar usados.

Glossário

TermoSignificado
Modelo de decisãoModelo que escolhe entre opções definidas antes e devolve a probabilidade de cada uma, em vez de escrever texto.
choice / noul / scoreTipos de pergunta: escolha de uma opção, sim/não, e nível ordinal.
LoRATécnica que ajusta só pequenas matrizes do modelo, barata o bastante para o Colab gratuito.
CalibraçãoAjuste para que 90% de confiança signifique acertar cerca de 90% das vezes.
ECEErro de calibração esperado: distância média entre confiança e acerto. Menor é melhor.
Temperature scalingDivide os logits por um número T para suavizar ou afiar as probabilidades sem mudar a decisão.
Gold / gabaritoAs respostas consideradas certas no treino. Podem ter sido geradas por outro modelo.
ProfessorO modelo que gerou o gold.
Teto do professorQuanto uma nova resposta do professor concorda com o gold. Passar disso indica decoração.
Lacuna humanaDiferença entre concordar com o gold e concordar com um analista.
ACHAnálise de Hipóteses Concorrentes (Heuer): vence a hipótese com menos evidência contra.
Escala do AlmirantadoAvaliação de fonte (A–F) e de informação (1–6), como B2.
Cadeia de custódiaRegistro que prova que evidências e resultados não foram alterados.
Zero-shotUsar o modelo numa tarefa sem treino específico para ela.
